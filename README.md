# Igreja Reformada Comunidade da Cruz · Landing Page

Landing page oficial da **Igreja Reformada Comunidade da Cruz**, localizada no bairro Serraria em Maceió – AL.

## 📌 Sobre o Projeto

Este projeto foi construído para apresentar a identidade, horários, doutrina, frentes missionárias no Sertão Alagoano, Instituto Missio Dei, eventos e canais de contato da igreja.

### 🚀 Funcionalidades
- **Programação Semanal Interativa**: Horários da Escola Bíblica Dominical, Culto de Adoração, Santa Ceia e Reunião de Oração.
- **Área Missionária & Sertão**: Destaque das frentes missionárias no Sertão de Alagoas e obreiros apoiados.
- **Instituto Missio Dei**: Frente teológica com integração de PIX exclusivo (QR Code + Cópia em 1 clique).
- **Cartão de Visitante com Integração WhatsApp**: Formulário que gera a mensagem formatada e abre diretamente no WhatsApp da secretaria.
- **Contribuições & PIX da Igreja**: Chaves PIX e dados bancários institucionais com botão de copiar rápido e Toast.
- **Mídia & Transmissões**: Integração para transmissões ao vivo de cultos e galeria de fotos da comunidade.
- **Design Responsivo & Efeitos**: Navegação fluida, menu drawer mobile, scroll reveal e visual moderno.

## 🛠️ Tecnologias Utilizadas
- **HTML5 Semântico**
- **CSS3 Vanilla** (Variáveis CSS, Flexbox, CSS Grid, Glassmorphism, Animações)
- **JavaScript Moderno (ES6+)** (Intersection Observer API, Clipboard API, Dynamic Modals)
- **Font Awesome 6 & Google Fonts** (*Cinzel*, *Plus Jakarta Sans*, *Playfair Display*)

## 💻 Como Executar Localmente

Basta abrir o arquivo `index.html` em qualquer navegador ou iniciar um servidor local:

```bash
# Com Python 3
python3 -m http.server 3000

# Com Node (npx)
npx serve .
```

Acesse em seu navegador através de: `http://localhost:3000`
